XAUAT-Classes
=============

西安建筑科技大学课表桌面组件（只读展示版）。

打开方式
--------
双击 XAUAT-Classes.exe（或桌面快捷方式）。

第一次打开：先出现登录页，输入学号与密码 → 程序自动完成统一身份认证并抓取整学期课表
→ 直接进入课表页。密码用 Windows DPAPI 加密后保存在本机（只有你这个 Windows 账户能解开）。
之后每次打开：直接进入课表页，不再问账号密码；窗口默认出现在屏幕中心。

怎么用
------
· 看课表：今天那一列高亮，"下一节"那节课带呼吸光晕
· 切周：拖动顶部"学期负载线"，或点线上任意一点；也可以用 ← → 方向键、Home 回本周
· 看课程：点课程块 → 弹出小卡片（课程名 / 教室 / 上课时间与距今时间 / 教师），鼠标移开自然淡出
· 收起：点标题栏「—」收进托盘（左键显隐，右键有菜单：置顶 / 开机自启 / 重置位置 / 退出）
· 折叠：双击标题栏变成小条
· 设置（⚙）：只有三样 —— 主题（亮色 / 暗色）、刷新课表、退出登录

没有的功能
----------
课表是只读的：不能新增、修改、删除、复制课程，也不能拖动课程换时间。
数据只来自教务系统本身，程序内不保存任何"示例课表"。

遇到人机校验
------------
如果教务系统要验证码，登录页会直接把图显示出来，你填进去即可。
如果是滑块、风控、访问频率限制等程序无法自动完成的校验，登录页会原样显示服务器提示，
并给出「在浏览器里打开」与「完成，重试」两个按钮。程序不做任何绕过或破解。

数据与文件
----------
课表与登录态：%AppData%\XAUAT-Classes\schedule.json
（里面只有课表数据和 DPAPI 加密后的密码密文，磁盘上没有明文密码）

关于体积
--------
自包含单文件发布，约 166 MB，不需要安装 .NET 运行时。
WPF 不支持裁剪，这是该技术路线的体积下限。

小提示
------
把 exe 挪到别的目录后，开机自启需要重新勾一次（注册表里存的是绝对路径）。
